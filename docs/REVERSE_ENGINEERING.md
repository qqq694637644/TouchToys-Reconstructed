## Recovered code

ILSpyCmd generated the first C# project from `TouchToys.dll`. The published source tree retains the application namespaces and editable C# files. WinRT generic-instantiation helper stubs generated by the original compiler are excluded from compilation because the current WinRT source generator supplies them again.

The first clean build exposed several decompiler artifacts. These were repaired rather than hidden with compiler suppressions:

- Touch-contact current coordinates and start coordinates were confused by decompilation. The reconstructed gesture code now computes movement and pinch distances from the correct points.
- Native pointer message switch constants were emitted as `ulong` patterns against `nuint` values. They were converted to native-unsigned constants.
- A QR scanner method contained an unassigned local used only by decompiler-generated no-op expressions. Those expressions were removed.
- The generated `RefSafetyRules` assembly attribute was removed so the current compiler can emit its own metadata.

## XAML recovery

The package contains a compiled `App.xbf` resource but no original `.xaml` source files. `App.xaml` was recovered by decompiling the XBF 2.1 MUX resource with XbfKit 0.4.0, then checking an XAML -> XBF -> XAML round trip. The editable XAML is compiled back to `App.xbf` by `tools/XbfCompiler` before the app build. The recovered markup preserves the application resource dictionaries and theme resources; original comments and formatting cannot be recovered.

## Signing and capabilities

The production package manifest retains `runFullTrust` and `uiAccess`. A production MSIX must be signed with an appropriate trusted publisher certificate. No original certificate or private key is redistributed.

CI uses a separate manifest without `uiAccess` and an ephemeral self-signed certificate. That allows package installation and UI/touch smoke tests on a GitHub-hosted Windows runner, but does not validate elevated-window redirection that depends on UIAccess trust.

## Validation

The internal `--smoke-test` path writes `smoke-test.json`; `--touch-smoke` also writes `touch-smoke.txt`. The test suite captures UI screenshots into `TOUCHTOYS_TEST_OUTPUT_DIR`. GitHub Actions uploads these files with the architecture-specific MSIX package.
